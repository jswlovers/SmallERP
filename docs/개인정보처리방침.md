# SmallERP 개인정보처리방침 (초안)

> 이 문서는 초안입니다. `[ ]`로 표시된 사업자 정보를 실제 값으로 채우고 법률 검토를 거친 뒤 게시하세요.

시행일자: `[YYYY-MM-DD]` (초안 작성 2026-09-27)

`[회사명]`(이하 "회사")은 서비스 "SmallERP" 제공에 필요한 최소한의 개인정보를 다음과 같이 수집·이용합니다. 이 방침은 (1) 회사와 회원(매장) 사이에서 회사가 직접 수집하는 정보와, (2) 회원이 자신의 고객을 관리하기 위하여 서비스에 등록하고 회사가 회원의 위탁을 받아 처리하는 정보를 함께 다룹니다.

## 제1조 (개인정보의 수집 항목과 방법)

### 1. 회원(매장) 정보 — 회사가 직접 수집
| 항목 | 수집 방법 |
|---|---|
| 매장명, 대표자명, 로그인 아이디, 비밀번호(해시 저장) | 회원가입 시 직접 입력 |
| 직원 계정 정보(이름, 연락처 — 암호화 저장) | 회원이 직원 등록 시 입력 |
| 접속 IP, 접속 일시, 서비스 이용 기록 | 서비스 이용 시 자동 수집 |

### 2. 고객(매장의 최종 이용자) 정보 — 회원의 위탁을 받아 처리
회사는 회원이 서비스에 등록·관리하는 고객 정보를 회원의 지시에 따라 처리하는 수탁자(처리위탁을 받는 자)의 지위를 가집니다. 이 항목의 개인정보에 대한 처리 목적과 법적 책임은 원칙적으로 회원(매장)에게 있습니다.

| 항목 | 수집 방법 |
|---|---|
| 고객 이름, 연락처(암호화 저장, 검색용 해시값 별도 보관) | 회원이 직접 등록, 또는 고객이 온라인 예약/AI 예약 도우미 이용 시 직접 입력 |
| 예약, 방문, 시술, 매출 이력 | 서비스 이용 시 자동 기록 |
| 정액권·회원권·포인트 보유·사용 내역(회원이 자체 운영) | 서비스 이용 시 자동 기록 |
| 문자 수신동의 여부와 동의 시각 | 고객 등록 또는 온라인 예약 가입 시 |
| 온라인 예약 인증번호(OTP) — 해시로만 저장, 원문 미보관 | 온라인 예약 가입·인증 시 |
| AI 예약 도우미 대화 내용 | AI 예약 도우미 이용 시 |
| 네이버 예약을 통해 접수된 예약자 이름·연락처·예약 시간 | 회원이 네이버 예약 연동을 설정한 경우, 웹훅으로 수신 |

## 제2조 (개인정보의 수집·이용 목적)
| 목적 | 이용하는 항목 |
|---|---|
| 회원가입 및 계정 관리, 서비스 이용료 정산 | 매장명, 대표자명, 로그인 정보 |
| 회원의 고객관리(CRM) 기능 제공 | 고객 이름, 연락처, 이력 |
| 예약 관리 및 온라인 예약·AI 예약 도우미 제공 | 고객 연락처, 예약 정보, 대화 내용 |
| 예약·마케팅 문자 발송 | 고객 연락처, 수신동의 여부 |
| 네이버 예약 연동 | 네이버로부터 수신한 예약자 정보 |
| 부정 이용 방지, 서비스 장애 대응, 분쟁 해결 | 접속 기록, IP 주소, 이용 기록 |
| 서비스 이용 통계 및 개선 | 서비스 이용 기록 |

## 제3조 (개인정보의 보유·이용 기간)
회사는 원칙적으로 개인정보의 수집·이용 목적이 달성되거나 이용계약이 종료되면 지체 없이 파기합니다. 다만 다음의 경우에는 명시한 기간 동안 보관합니다.

| 항목 | 보유 기간 | 사유 |
|---|---|---|
| 회원(매장) 가입 정보 | 이용계약 종료 시까지 | 서비스 제공 |
| 고객 정보(이름, 연락처, 이력) | 회원의 삭제 요청 시 또는 이용계약 종료 후 [기간] | 회원의 고객관리 목적, 소프트 삭제(`deleted_at`) 후 복구 지원 |
| 접속 IP 주소 및 접속 기록 | 3개월 | 「통신비밀보호법」 |
| 온라인 예약 인증번호(해시) | 인증 성공 또는 만료 후 단기간 | 부정 이용 방지 |
| AI 예약 도우미 대화 내용 | [기간] | 서비스 품질 관리, 분쟁 해결 |
| 계약 또는 청약철회, 대금 결제 기록 | 5년 | 전자상거래법 |
| 소비자 불만 또는 분쟁 처리에 관한 기록 | 3년 | 전자상거래법 |

## 제4조 (개인정보의 제3자 제공)
회사는 정보주체의 동의 없이 개인정보를 제3자에게 제공하지 않습니다. 다만 법령에 특별한 규정이 있는 경우 또는 수사기관이 법령에 정한 절차와 방법에 따라 요청하는 경우에는 예외로 합니다.

## 제5조 (개인정보 처리의 위탁)
회사는 서비스 제공을 위하여 개인정보 처리 업무의 일부를 다음과 같이 위탁합니다. 위탁 계약 시 개인정보의 안전한 관리에 관한 사항을 문서로 정하고 수탁자를 감독합니다.

| 수탁 업무 | 수탁자 | 비고 |
|---|---|---|
| 문자(SMS) 발송 | [문자 발송 대행사 — 연동 전까지 미사용, 현재 모의(mock) 발송] | 연동 완료 시 실제 상호로 갱신 |
| AI 예약 도우미 응답 생성 | Anthropic, PBC | 회원이 AI 예약 도우미를 활성화한 경우에 한하여, 대화 내용이 처리를 위해 전송됨. 국외 이전에 관한 사항은 제6조 참고 |

## 제6조 (개인정보의 국외 이전)
회사는 원칙적으로 개인정보를 국내에 위치한 서버에 보관합니다. 다만 회원이 AI 예약 도우미 기능을 활성화하여 고객이 이를 이용하는 경우, 아래와 같이 대화 내용이 국외로 이전됩니다.

| 이전받는 자 | 이전되는 국가 | 이전 항목 | 이전 목적 | 이전 시기·방법 |
|---|---|---|---|---|
| Anthropic, PBC | 미합중국 | AI 예약 도우미 대화 내용(고객이 입력한 이름·연락처가 포함될 수 있음) | 대화형 예약 응답 생성 | AI 예약 도우미 이용 시 API 호출을 통해 즉시 전송 |

## 제7조 (개인정보의 파기 절차와 방법)
1. 회사는 보유 기간이 경과하거나 처리 목적이 달성된 개인정보를 지체 없이 파기합니다.
2. 전자적 파일은 복구가 불가능한 방법으로 삭제합니다. 고객 정보는 삭제 요청 시 소프트 삭제(`deleted_at` 표시) 후 일정 기간이 지나면 완전 삭제합니다.
3. 법령에 따라 보존하여야 하는 정보는 다른 개인정보와 분리하여 저장·관리합니다.

## 제8조 (안전성 확보 조치)
1. 고객 연락처는 암호화하여 저장하며, 검색이 필요한 경우에는 원문을 복호화하지 않고 일방향 해시값을 이용합니다.
2. 온라인 예약 인증번호(OTP)는 해시로만 저장하며, 5회 초과 입력 시도, 재발송 60초 쿨다운, 번호당 1일 8회 발송 한도를 적용하여 남용을 방지합니다.
3. 회사는 접근권한 관리, 접속기록 보관, 전송 구간 암호화(TLS) 등 관리적·기술적 조치를 시행합니다.
4. 개인정보 유출 등 사고가 발생한 경우 지체 없이 정보주체에게 통지하고 관계기관에 신고합니다.

## 제9조 (정보주체 및 회원의 권리와 행사 방법)
1. 회원(매장)은 자신이 등록한 고객의 개인정보에 대한 열람, 정정, 삭제, 처리 정지를 서비스 내 화면에서 직접 수행할 수 있습니다.
2. 고객은 자신의 개인정보에 관하여 이용 중인 매장(회원)에 문의하거나, 온라인 예약 페이지의 "내 정보"·"내 예약" 화면에서 직접 열람·수정·취소할 수 있습니다.
3. 그 밖의 권리 행사는 서비스 내 메뉴, 전자우편(`[이메일]`), 서면 중 어느 방법으로도 할 수 있으며, 회사는 지체 없이 조치합니다.
