# 핸드SOS(HandSOS) 메뉴 트리 분석 및 SmallERP 대응표

조사일 2026-09-20. 대상: https://www1.handsos.com/ (→ 302로 https://www.handsos.com/ 이동, 로그인 전 화면)

## 0. 조사 범위와 신뢰도

| 출처 | 확인한 것 | 신뢰도 |
|---|---|---|
| **로그인 후 실제 프로그램 화면** (사용자가 제공한 계정으로 로그인, 읽기 전용) | 좌측 메뉴 10개 그룹과 하위 메뉴 105개, 상단 바, 대시보드, 기초설정·예약판·자동문자 화면 | **확정** (DOM에서 직접 추출) |
| 공개 웹사이트 | 상단·하단 메뉴 구조와 URL, 로그인 방식(회사코드+사용자ID+비밀번호), 가입 조건 | 확정 |
| 공식 유튜브 재생목록(영상 7개) 자동 자막 | 영상 1·2·4에서 각 기능의 사용 흐름·동작 규칙 | 참고(음성인식 오류 있음) |

조사 방법·주의: 로그인은 자동 브라우저로 했고 메뉴 이동과 화면 읽기만 했다(저장·삭제·문자 발송 없음). 매장의 고객 정보·사업자 정보는 문서에 옮기지 않았다. 캡처 이미지도 삭제했다.

### 2-3. 영상 자막에서 확인한 동작 규칙
- 네이버 예약 연동 후에는 **핸드SOS가 기준(원본)**. 파트너센터에서 바꾼 휴무·가능시간은 일정 시간 후 핸드SOS 값으로 덮어써진다.
- 전화 예약을 핸드SOS에 넣으면 같은 시간이 네이버에서 자동 차단된다. 핸드SOS에서 취소하면 네이버도 취소된다.
- 네이버페이 선결제·현장결제가 연계된 예약은 시간 변경 불가(취소 후 재예약).
- 매출 입력(이용 완료) 시 네이버 이용 완료가 되어 고객이 리뷰를 쓸 수 있다. "이용 완료" 시점은 "시술중 시/매출 입력 시" 중 선택.
- 이름+휴대폰이 일치하지 않는 네이버 예약은 "손님"으로 들어오고, 매출상세목록에서 기존 고객으로 매칭·이동한다.
- 디자이너별 네이버 매칭은 1:1. 직원 등록에 디자이너 이름이나 상품 이름을 등록해 매칭한다.
- 예약 알림을 담당 디자이너에게도 문자로 보낸다(네이버에는 없는 기능). 노쇼가 잦은 고객은 표시해 두면 네이버 예약 알림에 검정색으로 뜬다.
- 키오스크: 회원 검색(전화번호) → 담당자 → 큰 메뉴/하위 메뉴 → "지금 결제하기" 또는 "시술 후 결제하기", 회원 등록(개인정보 동의), 회원 없이 **간편 접수**(대기 접수 알림).
- 정액권 등록 예: 결제금액 50만원 → 사용가능금액 55만원(보너스) + 유효기간. 회원권은 횟수(예: 5회권) 차감.

### 4-1. 고객 셀프 온라인 예약 (2026-09-21 추가)

핸드SOS의 "모바일 홈페이지(온라인예약)"에 해당하는 기능을 자체 구현했다. 매장 직원 로그인과 완전히 분리된 흐름이다.

- **가입**: 비밀번호 없이 휴대폰 인증번호(OTP, 6자리, 5분 유효)만으로 가입·로그인한다. 이름은 선택 입력(미입력 시 "고객1234" 형태로 자동 지정, 나중에 수정 가능).
- **공유**: 매장마다 예약 페이지 링크(`/book.html?s=<공개코드>`)가 자동 발급된다. 설정 > 솔루션 간편설정에서 링크 복사·미리보기와 정책(온라인 예약 받기 on/off, 접수 즉시 자동확정 여부, 최소 리드타임, 최대 예약 가능일)을 관리한다.
- **예약 흐름**: 시술 선택(복수 가능) → 담당자 선택(또는 "담당자 무관"으로 자동 배정) → 날짜 선택 → 빈 시간 조회 → 예약. 기본 정책은 "확인필요(pending)" 상태로 접수되어 사장이 예약 화면에서 확정한다(자동확정으로 전환 가능).
- **직원 화면 반영**: 고객이 만든 예약은 소스가 "고객예약"으로 표시되어 예약 목록·타임테이블에서 네이버 예약과 구분된다. 담당 직원 알림 문자, 신규가입 자동 문자 등 기존 자동화 트리거가 그대로 작동한다.
- **보안**: 인증번호는 해시로만 저장, 시도 5회 초과·재발송 60초 쿨다운·번호당 하루 8회 한도로 남용을 제한한다. 예약 생성/취소/내 예약 조회는 본인 토큰으로만 가능하며, 매장 직원·관리자 토큰으로는 이 API를 쓸 수 없고 그 반대도 마찬가지다.
- **한계**: 문자 발송이 아직 mock이라 실제 SMS로 인증번호가 가지 않는다. 에이전시(Solapi 등) 연동 전까지는 ①운영 환경이 아닐 때 응답에 테스트용 인증번호(`devCode`)를 함께 내려주고 ②인증번호로 `000000`을 입력해도 항상 통과한다(둘 다 `NODE_ENV=production`에서 자동 비활성화, `src/public-service.js`).

### 4-2. AI 예약봇 — Claude 챗봇 구현 + ChatGPT Actions 연동 (2026-09-21 추가)

핸드SOS에는 없는 기능으로, 고객이 폼 대신 자연어 대화로 예약할 수 있다. 자세한 내용은 [docs/llm-booking-integration.md](llm-booking-integration.md) 참고.
