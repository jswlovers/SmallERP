# SmallERP 운영정책 (초안)

[이용약관](이용약관.md)이 "회사가 운영정책으로 정한다"고 위임한 기준 중 회원(매장)에게 공개되는 부분을 담은 문서입니다. 요금·제재의 구체적 수치는 서비스 운영 상황에 따라 변경될 수 있으며, 변경 시 공지합니다.

## 가입 심사 절차
회사는 신청일로부터 [기간] 이내에 결과를 통지합니다. 다음에 해당하는 경우 승인이 거절될 수 있습니다.
1. 필수 기재사항(매장명, 대표자명 등)을 누락하거나 허위로 기재한 경우
2. 과거 이용약관 위반으로 이용계약이 해지된 날로부터 1년이 지나지 않은 경우
3. 회사의 설비상 여유가 없거나 기술적 장애가 있는 경우

## 요금 정책
1. 서비스는 매장(회원) 단위로 이용료가 부과되며, 요금 체계는 별도 페이지 또는 안내를 통해 공지합니다.
2. 문자(SMS) 발송은 매장별 잔액(포인트) 방식으로 운영됩니다. 잔액은 관리자 화면에서 회사가 확인 후 충전하며, 자동 결제·충전 기능은 추후 제공될 예정입니다.
3. 잔액이 소진되면 문자 자동발송 기능이 제한되며, 예약·매출 등 핵심 기능 이용에는 영향을 주지 않습니다.

## 이용 정지·해지 기준
[이용약관](이용약관.md) 제16조의 금지행위별 조치입니다.

### 즉시 해지 사유
다음은 경고 없이 이용계약을 해지합니다.
| 위반 행위 | 근거 |
|---|---|
| 고객 개인정보를 목적 외로 이용하거나 제3자에게 제공 | 약관 제16조 제1호 |
| 서비스 무단 재판매·재임대, API 무단 대량 수집 | 약관 제16조 제2호 |
| 인증 우회, 취약점 악용 등 부정한 방법의 서비스 이용 | 약관 제16조 제3호 |

### 단계적 제재
| 위반 행위 | 1차 | 2차 | 3차 |
|---|---|---|---|
| 이용료 미납 | 경고(문자 발송 등 부가기능 제한) | 서비스 이용 일부 정지 | 이용계약 해지 |
| 서비스 운영 방해(과도한 부하 유발 등) | 경고 | 7일 정지 | 해지 |

### 제재 시 지켜지는 원칙
1. 제재 전에 회원에게 소명 기회를 드립니다. 다만 긴급하거나 중대한 위반은 조치 후 통지할 수 있습니다.
2. 제재 사유와 근거 조항, 이의신청 방법을 함께 통지합니다.
3. 해지 시 잔여 이용료·미사용 문자 잔액의 환불은 [이용약관](이용약관.md) 제14조에 따릅니다.

## 온라인 예약·AI 예약 도우미 남용 방지 정책
| 기준 | 내용 |
|---|---|
| 인증번호(OTP) 유효시간 | 5분 |
| 인증 시도 한도 | 5회 초과 시 재발송 필요 |
| 재발송 쿨다운 | 60초 |
| 번호당 일일 발송 한도 | 8회 |
| 운영 환경(`NODE_ENV=production`) 외 개발용 우회 | 응답에 `devCode` 포함, 인증번호 `000000` 항상 통과 — 운영 환경에서는 자동 비활성화 |

AI 예약 도우미는 `ANTHROPIC_API_KEY`가 설정된 매장에서만 활성화되며, 미설정 시 503으로 안전하게 비활성화됩니다.

## 네이버 예약 연동 정책
1. 네이버 예약과의 연동은 웹훅 수신 방식으로 동작하며, 회원별 공유 시크릿(`NAVER_WEBHOOK_SECRET`)으로 인증합니다.
2. 동일한 외부 예약 번호(`externalId`)로 재수신된 요청은 갱신(멱등) 처리되어 중복 예약이 생성되지 않습니다.
3. 공식 제휴 및 실제 페이로드 연동 전까지는 자체 정의한 예약 스펙(`externalId`, `name`, `phone`, `startAt` 등)을 기준으로 동작하며, 연동 확정 시 매핑을 조정하여 공지합니다.

## 신고·문의 처리
| 단계 | 내용 | 기한 |
|---|---|---|
| 접수 | 문의·신고 내용 기록 | 즉시 |
| 확인 | 필요 시 로그·이용 기록 확인 | [기간] |
| 처리 및 통지 | 처리 결과를 신청인에게 통지 | [기간] |

## 데이터 백업과 장애 대응
1. 회원(매장)이 등록한 고객 정보는 회원이 서비스 내 CSV 내보내기 기능을 통해 직접 백업할 수 있습니다.
2. 서버 장애, 인증서 만료 등으로 서비스 접속이 불가능한 경우 회사는 확인 즉시 조치하며, 장기간 중단이 예상되는 경우 사전 또는 사후에 공지합니다.

자세한 이용 조건은 [이용약관](이용약관.md), 개인정보 처리에 관한 사항은 [개인정보처리방침](개인정보처리방침.md)을 확인해주세요.
